# ⚔️ Funcionalidades do EnderP

## 🌎 Sistema de Nações

O EnderP possui um sistema de nações criado para incentivar interação entre jogadores, criando diferentes identidades e estilos de gameplay.

### Recursos:

- Escolha de nação;
- Benefícios específicos;
- Organização por grupos;
- Expansão futura para territórios e eventos.

---

# 🏕️ Sistema Nômade

Uma experiência alternativa para jogadores que preferem explorar o mundo sem pertencer a uma nação.

### Recursos:

- Entrada independente;
- Exploração livre;
- Sistema de sobrevivência individual.

---

# 🎁 Sistema de Drops e Eventos

Sistema de eventos dinâmicos para aumentar a interação no servidor.

### Recursos:

- Recompensas personalizadas;
- Eventos no mapa;
- Incentivo à exploração.

---

# 💰 Sistema Econômico

Sistema pensado para criar uma economia baseada em atividades dos jogadores.

Possíveis áreas:

- Comércio;
- Recursos;
- Recompensas;
- Progressão.

---

# 🌐 Integração Multiplataforma

O servidor utiliza tecnologias para permitir jogadores de diferentes plataformas.

Compatibilidade:

- Minecraft Java Edition;
- Minecraft Bedrock Edition.

---

# ⚙️ Sistemas Personalizados

O projeto utiliza configurações e scripts próprios para criar funcionalidades exclusivas.

Exemplos:

- Teleportes personalizados;
- Menus interativos;
- Hologramas;
- Sistemas automatizados.

---

# 🚀 Expansões futuras

Planejado:

- Sistema avançado de territórios;
- Mais eventos;
- Novas mecânicas;
- Melhorias de escalabilidade.
