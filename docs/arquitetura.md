# Arquitetura do EnderP

## Visão geral

O EnderP é um projeto de servidor multiplayer baseado em uma arquitetura PaperMC, utilizando plugins, sistemas personalizados e integração multiplataforma.

## Estrutura técnica

### Servidor

- PaperMC
- Minecraft Java Edition
- Suporte Bedrock através de Geyser/Floodgate

### Sistemas

- Gerenciamento de jogadores
- Sistema de nações
- Economia
- Teleporte
- Eventos
- Drops personalizados

## Objetivo da arquitetura

Criar uma infraestrutura organizada, escalável e preparada para crescimento futuro.
